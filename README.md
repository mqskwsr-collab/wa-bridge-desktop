# WA Bridge Desktop

אפליקציית Windows בסגנון וואטסאפ מעל שרת ה-WA Bridge (`mqskwsr-collab/users`).
אנשי הקשר וההיסטוריה נשמרים **בשרת**, והאפליקציה רק מציגה אותם. ההודעות נשלחות בפועל מהטלפון.

## התקנה
1. היכנס ל-**Releases** בריפו הזה והורד את `WA-Bridge-Setup-<גרסה>.exe`.
2. הרץ אותו. ההתקנה היא למשתמש הנוכחי, ללא הרשאות מנהל, ואחריה נוצרים קיצורים בשולחן העבודה ובתפריט התחל.
3. בהפעלה הראשונה: הדבק את **הקישור האישי** (בדשבורד: "אזור אישי") והסיסמה של האזור האישי.

Windows עשוי להציג "SmartScreen" כי ההתקנה לא חתומה בתעודה: "מידע נוסף" ← "הפעל בכל זאת".

## מה יש בה
- **תמונות וקבצים:** תמונה שהגיעה אליך מוצגת בתוך השיחה (לחיצה מגדילה, "שמור…" שומר למחשב). לשליחה: כפתור 📎, הדבקה (Ctrl+V) של תמונה מהלוח, או גרירה של קבצים לחלון השיחה, עם תצוגה מקדימה לפני השליחה. שליחה אפשרית רק לאיש קשר **עם מספר טלפון** (לא לקבוצה ולא ל-Meta AI), כי הטלפון שולח אותם דרך המספר.
  התמונות נשמרות בדיסק של השרת (עד 200MB למשתמש, ונמחקות עם ההודעה שלהן). ב-Render החינמי הדיסק מתאפס בכל הפעלה מחדש של השרת, ואז תוצג רק שם הקובץ.
- **כמה מספרים:** לחיצה על השם למעלה פותחת את רשימת המספרים. "הוסף מספר" מבקש קישור אישי וסיסמה של מספר נוסף. מעבר מהיר עם Ctrl+1…9, ספירת הודעות שלא נקראו והתראה גם על המספר שלא פתוח.
- **דוח מצב (📊):** האם השרת והטלפון מחוברים, מה ממתין בתור, כמה נשלח ונכשל ב-24 שעות, ולמה נכשלו.
- **איפה ההודעה? (ⓘ ליד כל הודעה שנשלחה):** מסלול ההודעה (נוצרה, הטלפון לקח, נשלחה) עם זמנים, ואבחון בעברית. הוא מבחין בין "הטלפון לא מחובר", "ממתינה בתור", "נשלחה" ו"נכשלה (והסיבה)". הגבלה: "נשלחה" אומר שהטלפון העביר את ההודעה לוואטסאפ. המערכת לא רואה וי כפול או כחול, ולכן אם הנמען לא ענה אי אפשר לדעת אם הוא עסוק או לא ראה. תשובה ממנו אחרי ההודעה מוכיחה שהיא הגיעה.
- רשימת שיחות עם חיפוש, מונה הודעות שלא נקראו, ושיחה בסגנון וואטסאפ
- שיחה חדשה עם מספר טלפון (איש הקשר נשמר בשרת) וקבוצות
- שליחת טקסט וקבצים, ביטול הודעה שעוד לא נשלחה, סטטוס (ממתין / נשלח / נכשל)
- התראות Windows להודעות נכנסות, גם כשהחלון סגור (האפליקציה רצה ליד השעון)
- סמל ליד השעון (System Tray): מספר הגרסה בהצבעה ובתפריט, נקודה אדומה להודעות חדשות, נקודה כתומה כשעדכון מוכן
- הפעלה עם Windows (אפשר לכבות בהגדרות)
- מצב כהה אוטומטי

## עדכון אוטומטי
העדכונים (והתקנה הראשונית) עוברים **דרך שרת ה-WA Bridge**, ולכן הריפו הזה יכול להיות פרטי: לשרת יש טוקן קריאה בלבד ל-GitHub (`DESKTOP_RELEASES_TOKEN`), והוא מוסר קבצים רק לאפליקציה מחוברת. שום טוקן לא נמצא בתוך ה-exe.
ההתקנה הראשונה: האזור האישי באתר ← "אפליקציה ל-Windows" ← "הורד התקנה".

האפליקציה בודקת עדכונים 15 שניות אחרי ההפעלה ואז כל 3 שעות, מורידה ברקע, ומציגה התראה.
"התקן עדכון" בתפריט המגש או בהגדרות מפעיל מחדש ומתעדכן. אם לא לוחצים, העדכון מותקן בפעם הבאה שהאפליקציה נסגרת.

### איך משחררים גרסה חדשה (אחרי שינוי)
```
# 1. מעלים את "version" ב-package.json, למשל ל-1.0.1
git commit -am "v1.0.1: מה שונה"
git tag v1.0.1
git push && git push --tags
```
GitHub Actions בונה את ה-exe ומפרסם Release. כל המחשבים המותקנים יתעדכנו לבד.

## אבטחה
- ההתחברות היא עם סיסמת האזור האישי (ו-2FA אם הופעל). השרת מנפיק "מפתח מכשיר" שנשמר מוצפן ב-Windows (DPAPI); שינוי סיסמה באתר מנתק את כל המחשבים.
- החלון של האפליקציה לא ניגש לרשת: כל הקריאות עוברות דרך התהליך הראשי, רק לכתובות `/api/desk/*` של השרת שלך.
- היסטוריית הצ'אט נשמרת בשרת רק עבור חשבונות שמחוברת להם אפליקציה, לפי תקופת השמירה שנבחרה באזור האישי (ברירת מחדל 30 יום), ועד 3000 הודעות.
